# ⚖️AI-Powered Legal Information & Rights Retrieval Agent

**Legal Agent** is an AI agent designed to empower women in Pakistan by providing instant, source-attributed awareness of their legal rights (including Workplace Harassment Acts, Muslim Family Laws, and PPC provisions).

---

## 🎯 Key Features
- **Retrieval-Augmented Generation (RAG):** Grounded responses directly mapped to official statutes to avoid hallucinations.
- **Source Citation:** Returns specific sections and statutes alongside answers.
- **Interactive UI:** Built-in IPython widget interface for live querying.
- **Agile Developed:** Tracked and planned via Jira Kanban workflow.

---

## 🛠️ Tech Stack
- **Language:** Python 3.10+
- **Framework:** LangChain
- **Vector Database:** ChromaDB
- **Embeddings:** HuggingFace Sentence Transformers (`all-MiniLM-L6-v2`)
- **UI & Execution:** Google Colab / IPython Widgets
- **Project Management:** Jira
